PAC MEDIA - UPDATE v9 (November 2026) - PATCH NOTES
===================================================

HOW TO APPLY (git patch)
  1. Save pac-media-v9.patch into your project folder
     (C:\Users\User\Documents\pac).
  2. In the VS Code terminal:
       git pull
       git apply pac-media-v9.patch
       git add .
       git commit -m "v9: install page for Android, iPhone and desktop"
       git push
  3. Reload the app on your phone twice (first load fetches the new
     version, the second shows it).

  The patch does NOT touch config.js - your keys stay as they are.

WHAT'S NEW IN v9

  A real install page: install.html
  - Share this address with readers, clients and staff:
      your app address + /install.html
    (for example  https://your-site.vercel.app/install.html)
  - The page looks like an app-store listing for PAC Media: the
    app icon, the "Publishing Brands. Connecting Audiences."
    tagline and the Pigeon Advertising & Communications company
    paragraph, features, version info.
  - One big Install button that works on every phone:
      * Android (Chrome): opens the real one-tap install dialog -
        PAC Media lands on the home screen with its own icon.
      * iPhone / iPad (Safari): shows the 3-step Add to Home
        Screen guide, with the reader's own device highlighted.
      * Desktop (Chrome/Edge): installs PAC Media as its own
        window. Other browsers get manual steps.
  - The page knows when it is already running inside the
    installed app - then it simply shows "Open PAC Media" and
    takes the reader into the magazines.
  - Why this beats the browser version: readers never browse to
    the app address by accident - they install once and open PAC
    Media from its own icon, fullscreen, no address bar, working
    offline. Send them the /install.html link, not the app link.
  - A Share button lets anyone pass the install page along
    (WhatsApp, SMS, email - the phone's share sheet).

  Under the hood
  - install.html joins the service worker's offline cache
    (cache bumped to v9 - two reloads pick it up).
