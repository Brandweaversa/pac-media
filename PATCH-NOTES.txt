PAC MEDIA - UPDATE v3 (November 2026) - PATCH NOTES
===================================================

HOW TO APPLY (git patch - no file replacing needed)
  1. Save pac-media-v3.patch into your project folder
     (C:\Users\User\Documents\pac).
  2. In the VS Code terminal:
       git pull
       git apply pac-media-v3.patch
       git add .
       git commit -m "v3: Inter font, splash logo fix, red logo tiles"
       git push
  3. Supabase Dashboard > SQL Editor > New query > paste the whole
     database-update.sql > Run.  <<< THIS IS THE STEP THAT FIXES
     "The database is missing the new settings columns"
  4. Reload the app on your phone twice (first load fetches the new
     version, second shows it).

  The patch does NOT touch config.js - your keys stay as they are.

WHAT'S NEW IN v3

  Professional look - Inter font
  - The entire app now uses Inter (the font used by modern apps like
    Vercel and GitHub), with softer shadows, rounded buttons that
    respond to touch, and a subtle fade-in on every screen.

  Splash screen - text placeholder removed completely
  - The built-in "PAC" text placeholder logo no longer exists in the
    app. The splash shows ONLY your uploaded logo (loaded from your
    database, remembered on the phone so it appears instantly).
    Before the logo arrives the splash is simply the red screen.
  - assets/pac-logo.png has been deleted from the project.

  Magazine hub - red tiles
  - Every magazine now sits on a RED TILE (your brand red) with its
    logo centered on it - this is why logos that are white or light
    (like your Travel Passport logo, which is tan on transparency)
    finally show up properly instead of disappearing into the white
    background or showing as text.
  - A magazine without a logo shows its name in white on the red tile.
  - The magazine page shows the same red tile.
  - Rounded corners, border thickness and border color are still
    controlled in Dashboard > Branding > Magazine logos (border now
    defaults to white, which frames the red tile).

  Install banner
  - Once the app has been installed (opened from the home screen
    icon) even once, the banner never appears again on that device -
    not in the installed app and not in the browser.
  - The X button still closes it for the current visit, and it is
    offered again on the next visit until installed.

  Settings that could not save - fixed two ways
  - The database update (step 3 above) adds the missing columns, so
    all logo style settings save normally.
  - Until the update is run, the app now saves what it can (the logo
    width) and clearly tells you what still needs the database update,
    instead of failing the whole save.

  Security hardening (in database-update.sql)
  - An older repair script had allowed ANY signed-in account to edit
    magazines and issues. The database update now locks writes to your
    administrator account only. Reading stays public.

  Also in v3 (carried from v2)
  - Issue covers displayed uncropped on top of the issue name, the
    issue page shows the cover, "Open Flipbook" button, swipe between
    screens, footer pinned just above the bottom navigation, upload
    errors no longer lose your data.

IF THE LOGO STYLE SETTINGS STILL SAY "database is missing columns"
  database-update.sql has not run yet on your Supabase project.
  Supabase Dashboard > SQL Editor > New query > paste the whole file
  > Run. It is safe to run it any number of times.
