PAC MEDIA - UPDATE v5 (November 2026) - PATCH NOTES
===================================================

HOW TO APPLY (git patch)
  1. Save pac-media-v5.patch into your project folder
     (C:\Users\User\Documents\pac).
  2. In the VS Code terminal:
       git pull
       git apply pac-media-v5.patch
       git add .
       git commit -m "v5: install banner back, fullscreen flipbook"
       git push
  3. Reload the app on your phone twice (first load fetches the new
     version, the second shows it).

  The patch does NOT touch config.js - your keys stay as they are.

WHAT'S FIXED IN v5

  Install banner is back - in the browser too
  - Cause found: the app permanently remembered "this person has
    installed before", and that memory made it hide the banner
    everywhere, forever, even in the normal browser.
  - That memory is gone. The install offer now appears on every
    visit in the browser until the app is actually installed - or
    until you close it with the X (then it stays closed just for
    that visit).
  - In the installed app itself the banner still never appears
    (that is by design - you are already using the app).
  - Where the browser can offer the one-tap install dialog, the
    banner button opens it; otherwise it opens clear step-by-step
    install instructions for Android and iPhone.

  "Read Issue" now opens the flipbook FULLSCREEN
  - Tapping a magazine cover no longer shows a half-page reader
    squeezed under a header, a cover image and bars. The flipbook
    now fills the entire screen edge to edge, exactly like the
    source flipbook site, so all of the flipbook's own buttons
    (zoom, page navigation, thumbnails, sound, share...) are
    visible and usable.
  - Two small floating buttons stay out of the way on top:
    "<- Back" (left) returns to the magazine page and "Open ->"
    (right) opens the flipbook in a browser tab if the host ever
    refuses to embed.
  - Bottom navigation and the footer hide themselves while reading
    and come back when you return to the magazine.

  Under the hood
  - Service worker cache bumped to v5 (every device picks this up
    with two reloads).

CARRIED FROM v4 (already in your app)
  - Red strip with the small square logo on every page, no
    "PAC MEDIA" text heading.
  - Magazine logos directly on the page (no red background) with
    configurable rounded border.
  - Working banner X button and Install button; reader loading
    cover disappears when the flipbook is ready; no more raw
    "&#8230;" text.
  - Splash logo no longer resizes mid-load; splash height honoured.
  - Inter font across the app; database locked to your admin
    account.
