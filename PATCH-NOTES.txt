PAC MEDIA - UPDATE v6 (November 2026) - PATCH NOTES
===================================================

HOW TO APPLY (git patch)
  1. Save pac-media-v6.patch into your project folder
     (C:\Users\User\Documents\pac).
  2. In the VS Code terminal:
       git pull
       git apply pac-media-v6.patch
       git add .
       git commit -m "v6: clean fullscreen flipbook, no overlay buttons"
       git push
  3. Reload the app on your phone twice (first load fetches the new
     version, the second shows it).

  The patch does NOT touch config.js - your keys stay as they are.

WHAT'S CHANGED IN v6

  The flipbook screen is now completely clean
  - The floating "<- Back" and "Open ->" buttons are gone. They
    covered parts of the magazine pages.
  - The popup "If the magazine does not appear..." is gone too.
    You confirmed the flipbook opens fine, so there is nothing to
    warn about - and nothing sits over the magazine anymore.
  - Tapping "Read Issue" now shows ONLY the flipbook, full screen,
    edge to edge, with the flipbook's own buttons (zoom, page
    navigation, thumbnails, share...) all visible and unobstructed.
  - While the magazine loads, a "Loading magazine..." screen shows
    briefly and disappears by itself the moment the flipbook is
    ready. That is not a popup - it never covers a loaded page.

  How to get back to the magazine page
  - Use your phone's normal Back: the system back button/gesture
    (Android), or swipe from the left edge (iPhone in Safari).
    In the installed Android app the back button returns from the
    flipbook to the magazine page, exactly as before.

CARRIED FROM v5 (already in your app)
  - Install banner shows on every visit in the normal browser
    (Android gets the one-tap Install dialog; other phones get
    step-by-step instructions). It never appears inside the
    installed app, and the X closes it just for that visit.
  - Bottom navigation and the footer hide while reading and come
    back on the magazine page.
  - Service worker cache bumped to v6 (every device picks this up
    with two reloads).
