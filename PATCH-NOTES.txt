PAC MEDIA - UPDATE v7 (November 2026) - PATCH NOTES
===================================================

HOW TO APPLY (git patch)
  1. Save pac-media-v7.patch into your project folder
     (C:\Users\User\Documents\pac).
  2. In the VS Code terminal:
       git pull
       git apply pac-media-v7.patch
       git add .
       git commit -m "v7: back button on magazine page, no duplicate name"
       git push
  3. Reload the app on your phone twice (first load fetches the new
     version, the second shows it).

  The patch does NOT touch config.js - your keys stay as they are.

WHAT'S CHANGED IN v7

  The magazine page (the one listing all issues)
  - Added a Back button. It sits just below the red strip, on the
    left, and returns you to the magazines hub. The page never had
    one - the only way out was the phone's system back.
  - Removed the magazine name text that sat under the magazine
    logo. The logo already says who it is, so the name was just a
    duplicate. The small red dash under the logo stays.
  - If a magazine ever has no logo uploaded, its name still shows
    in the logo's place - that fallback is untouched.

CARRIED FROM v6 (already in your app)
  - Flipbook opens clean and fullscreen: no floating Back/Open
    buttons, no popup - only the magazine and its own controls.
    Back out of the flipbook with the phone's system back
    (or left-edge swipe on iPhone in Safari).
  - Install banner shows on every visit in the normal browser
    (Android gets the one-tap Install dialog; other phones get
    step-by-step instructions). It never appears inside the
    installed app, and the X closes it just for that visit.
  - Service worker cache bumped to v7 (every device picks this up
    with two reloads).
